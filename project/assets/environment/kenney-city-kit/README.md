# Kenney City Kit – Suburban assets

Imported GLB models: building-type-a.glb through building-type-f.glb, tree-large.glb, tree-small.glb, and fence.glb.

Source pack: https://kenney.nl/assets/city-kit-suburban
Author: Kenney
License: CC0 1.0 Universal (see LICENSE.txt). Commercial use and modification are permitted; attribution is not required, but appreciated.

These are lightweight low-poly environment props, not photorealistic military buildings. Combine selectively with the existing soldier and tank assets; do not represent them as realistic military architecture.

Original mirror used to import the GLB files: https://github.com/petroulacl/fps-buildings-env-kit
