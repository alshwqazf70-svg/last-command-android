# خطة البناء والاختبار

## المرحلة 0 — إثبات سلسلة البناء
1. تثبيت قرار المحرك بناءً على توفر بناء Android في GitHub Actions.
2. بناء مشروع تجريبي فارغ.
3. حفظ APK كـ workflow artifact.
4. تثبيت APK فعلياً على جهاز Android 10.
5. تسجيل حجم APK ونتيجة التشغيل ومعدل الإطارات واستهلاك الذاكرة.

**بوابة قبول:** لا يبدأ إنتاج محتوى اللعبة قبل نجاح APK تجريبي قابل للتثبيت.

## المرحلة 1 — نموذج قابل للعب
- مشهد قاعدة بسيط.
- تحكم لمس.
- شخصية واحدة.
- سلاح واحد.
- أعداء أساسيون.
- مهمة قصيرة ومكافأة.
- حفظ محلي.

## المرحلة 2 — أنظمة التقدم
- موارد وإنتاج وترقية مبانٍ.
- مجموعة أبطال وتشكيلات.
- تدريب قوات ومعدات وأبحاث.

## المرحلة 3 — محتوى أوسع
- مراحل قتالية متنوعة وزعماء.
- قاعدة موسعة.
- خريطة استراتيجية ومهام.

## المرحلة 4 — الاتصال الجماعي
- حسابات ومزامنة.
- تحالفات وتجمعات.
- خادم يتحقق من المعارك والاقتصاد.
- أحداث ومواسم.

## بوابة الجودة لكل إصدار
- نجاح الفحص الآلي.
- عدم وجود أخطاء حرجة.
- حفظ واسترجاع سليم.
- تثبيت وتشغيل APK على جهاز فعلي.
- اختبار جلسة لعب مستمرة ورصد الأداء والحرارة.
