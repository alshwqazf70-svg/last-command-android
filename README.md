# Last Command

لعبة استراتيجية وبناء مدن ثلاثية الأبعاد للأجهزة المحمولة، مبنية باستخدام Godot 4.

## المرحلة الحالية: Vertical Slice 0.6 — نظام حصار ودفاع المدينة
- مدينة ثلاثية الأبعاد أولية مع شبكة طرق ومنازل قابلة للبناء.
- شخصية قائد قابلة للحركة بأزرار لمس أو لوحة مفاتيح.
- ثكنة عسكرية تفتح التجنيد وترفع سقف الجيش إلى 20 وحدة.
- نوعان تجريبيان من الوحدات: مشاة ورماة، ولكل منهما تكلفة ومدى وضرر مختلف.
- موجات أعداء متزايدة العدد مع حركة باتجاه القائد وهجوم دوري.
- أبراج دفاعية تطلق هجمات تلقائية على الأعداء ضمن المدى.
- أسوار دفاعية مقسمة إلى قطاعات قابلة للتضرر والتدمير، مع فتحة بوابة رئيسية.
- بوابة قابلة للفتح والإغلاق، ويمكن أن تتعرض للهجوم والسقوط.
- الأعداء يهاجمون التحصينات عند الاقتراب من خارج المدينة، ثم ينتقلون إلى المباني بعد اختراق الدفاع.
- المباني السكنية لها نقاط صحة مستقلة ويمكن تدميرها.
- زر إصلاح يعيد صحة أقرب منشأة متضررة مقابل عملات وخشب وحديد.
- حفظ صحة قطاعات الدفاع وحالة البوابة واستعادتها عند تحميل اللعبة.
- اقتصاد بثلاثة موارد: الخشب والحديد والغذاء، مع إنتاج تلقائي كل 10 ثوانٍ.
- مباني إنتاج قابلة للبناء: منشرة خشب ومنجم حديد ومزرعة، ولكل منها إنتاج دوري.
- استهلاك الغذاء عند تجنيد المشاة والرماة.
- ترقية الثكنة إلى المستوى الثاني لرفع سقف الجيش إلى 30 وحدة.
- حفظ محلي لتقدم المدينة والموارد والمباني والجيش وموقع القائد، مع استعادة تلقائية عند تشغيل اللعبة وزري حفظ/تحميل.

## التشغيل
1. افتح المشروع في Godot 4.4.1.
2. شغّل المشهد الرئيسي `scenes/main.tscn`.
3. استخدم أزرار الاتجاهات أسفل الشاشة للحركة وأزرار البناء والتجنيد والدفاع.

## Android APK
يحتوي المستودع على GitHub Actions لإعداد قوالب Godot ومستلزمات Android ثم تصدير APK تجريبي. بعد نجاح التشغيل، سيكون الملف ضمن Artifact باسم `LastCommand-Android-Debug` في صفحة Actions.

## خارطة الطريق
1. التحقق من تصدير APK واختباره على جهاز Android.
2. إضافة حفظ محلي واستعادة التقدم (نسخة أولية منفذة).
3. تحسين واجهة الهاتف والكاميرا والحركة.
4. تطوير أنواع الوحدات وترقياتها وسلوك القتال.
5. توسيع نظام الحصار ليشمل مسارات اقتحام متعددة، بوابات إضافية، أبراجاً قابلة للتدمير، وأوامر دفاع للجيش.
6. إضافة مبانٍ إنتاجية وموارد وترقية الثكنة (نسخة أولية منفذة).
7. توسيع اقتصاد المدينة وربط الغذاء بالسكان وأنظمة الصيانة.
8. تحسين الرسومات والأداء وإضافة مناطق جديدة.

 > هذه نسخة Prototype تأسيسية. نظام الحصار الحالي خطوة أولى قابلة للاختبار والتوسعة؛ لم يُثبت بعد اختبار اللعب على جهاز Android فعلي.
