# Last Command

مشروع لعبة استراتيجية وبناء مدن ثلاثية الأبعاد للأجهزة المحمولة، باستخدام Godot 4.

## المرحلة الحالية: Vertical Slice 0.2
- مشهد ثلاثي الأبعاد خفيف باستخدام Compatibility renderer.
- شخصية قابلة للحركة بلوحة المفاتيح وأزرار لمس.
- مدينة أولية بطرق ومبانٍ وبناء منازل مقابل العملات.
- ثكنة عسكرية قابلة للبناء، ترفع سقف الجيش إلى 20 جندياً.
- تجنيد جنود بتكلفة موارد محددة.
- موجات أعداء قابلة للاستدعاء ويزداد عددها تدريجياً.
- أعداء يتحركون نحو القائد ويهاجمونه، مع مؤشر لصحة القائد.
- هجوم مباشر ومساندة تلقائية من الجنود ضمن نطاق الحماية.
- واجهة عربية مبسطة تعرض العملات والسكان والجيش والصحة والموجة.

## التشغيل
1. افتح المشروع في Godot 4.4.1.
2. شغّل المشهد الرئيسي: `scenes/main.tscn`.
3. على الهاتف، استخدم أزرار الاتجاهات أسفل اليسار وأزرار البناء والتجنيد والهجوم.

## التصدير إلى Android
يحتوي المستودع على GitHub Actions لتجهيز قوالب تصدير Godot ومفتاح Debug ثم إنشاء APK تجريبي. بعد نجاح التشغيل، نزّل ملف `LastCommand-Android-Debug` من قسم Artifacts في صفحة Actions.

## خارطة الطريق
1. تحسين الحركة والكاميرا وواجهة اللمس.
2. أنواع جنود مختلفة وترقيات للجيش والثكنة.
3. دفاعات المدينة والأبراج والأسوار.
4. اقتصاد وموارد ومبانٍ قابلة للترقية.
5. مهام واستكشاف ومناطق جديدة.
6. تحسين الأداء والتصدير إلى Android APK.

> هذه نسخة تأسيسية تجريبية قابلة للتوسع وليست اللعبة النهائية بعد. يجب اختبارها على جهاز Android فعلي قبل اعتبارها إصداراً مستقراً.
