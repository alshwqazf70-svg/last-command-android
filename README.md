# Last Command

مشروع لعبة استراتيجية وبناء مدن ثلاثية الأبعاد للأجهزة المحمولة، باستخدام Godot 4.

## المرحلة الحالية: Vertical Slice 0.1
- مشهد ثلاثي الأبعاد خفيف باستخدام Mobile/Compatibility renderer.
- شخصية قابلة للحركة بلوحة المفاتيح وأزرار لمس.
- مدينة أولية بطرق ومبانٍ.
- نظام أولي لبناء المنازل واستهلاك العملات وزيادة السكان.
- واجهة عربية مبسطة.

## التشغيل
1. افتح المشروع في Godot 4.4 أو إصدار 4.x متوافق.
2. شغّل المشهد الرئيسي: `scenes/main.tscn`.
3. على الهاتف، استخدم أزرار الاتجاهات أسفل اليسار وزر بناء المنزل.

## خارطة الطريق
1. تحسين الحركة والكاميرا وواجهة اللمس.
2. موارد واقتصاد ومبانٍ قابلة للترقية.
3. وحدات الجيش ونظام القتال.
4. مهام واستكشاف ومناطق جديدة.
5. تحسين الأداء والتصدير إلى Android APK.

> هذه نسخة تأسيسية قابلة للتوسع وليست اللعبة النهائية بعد.
